## 三、当前已知限制
1. 默认使用 Mock 数据，刷新页面会恢复初始数据；不能将其描述为真实数据库 CRUD。
2. 真实后端的课程、成绩、用户 Controller 路由与响应结构尚待团队确认。
3. 当前压缩包未包含登录页和完整 Token 生命周期；不能单独视为可上线的认证系统。
4. 学生角色通常不应拥有课程新增、编辑、删除权限。当前课程 CRUD 是便于小组演示的前端功能骨架，必须根据后端角色权限调整按钮显示，并由后端强制鉴权。
5. 课程删除应由后端检查是否存在成绩等关联数据，前端提示不能代替后端业务校验。
6. 成绩字段、总评算法、缺考/缓考状态和学分统计规则应与数据结构/需求分析文档保持一致。

## 四、结论
本版本提供 F 模块的前端页面骨架与演示交互，适合在团队仓库中继续开发。**当前不能宣称已完成端到端联调或真实后端测试**。建议完成依赖安装与生产构建后，依照用例逐项执行；后端接口稳定后补充联调记录、测试截图、缺陷修复情况与最终结论。
