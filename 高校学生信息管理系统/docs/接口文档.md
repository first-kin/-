## 1. 全局约定

### 1.1 基础信息

| 项 | 内容 |
| ---- | ---- |
| 基础地址 | 开发环境：`/api`（由 Vite 代理到后端 `http://localhost:8080`）；生产环境：`https://<域名>/api` |
| 协议 | HTTP/1.1 |
| 数据格式 | 请求与响应均为 `application/json`（文件上传/下载除外） |
| 字符编码 | `UTF-8` |
| 时间格式 | `yyyy-MM-dd HH:mm:ss` |

### 1.2 鉴权方式

除 `POST /api/auth/login` 外，所有接口必须在**请求头**携带 JWT：

```
Authorization: Bearer <token>
```

- Token 由登录接口签发，有效期默认 24 小时（对应 AUTH-02）。
- 后端由 `JwtFilter` 统一校验；未携带或校验失败返回 `code=1003`。
- 前端由路由守卫拦截未登录访问（对应 AUTH-06）。

### 1.3 统一响应格式

所有接口统一返回如下结构（对应「可维护性」非功能需求）：

```json
{
  "code": 0,
  "msg": "成功",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| code | int | 业务状态码，`0` 表示成功，非 `0` 表示失败 |
| msg  | string | 提示信息，可直接展示给用户 |
| data | object / array / null | 业务数据，失败时为 `null` |

> HTTP 状态码恒为 `200`；成功与否一律以 body 中的 `code` 区分（`0` 成功，非 `0` 失败，具体含义见 1.4 错误码表）。前端拦截器只需判断 `code`，无需区分 HTTP 状态码。

### 1.4 全局错误码表

| code | 含义 | 典型场景 |
| ---- | ---- | ----- |
| 0 | 成功 | — |
| 1001 | 参数校验失败 | 必填字段缺失、格式不合法 |
| 1002 | 用户名或密码错误 | 登录失败 |
| 1003 | Token 无效或已过期 | 鉴权失败 |
| 1004 | 无权限访问该资源 | RBAC 角色越权 |
| 1005 | 资源不存在 | 按 id 查询不到记录 |
| 1006 | 数据重复 | 学号/工号/课程名唯一约束冲突 |
| 1007 | 业务规则冲突 | 有成绩记录的课程禁止删除 |
| 2001 | 账号被锁定 | 连续输错 5 次锁定 10 分钟（AUTH-04） |
| 5000 | 服务器内部错误 | 未捕获异常 |

### 1.5 分页约定

**请求参数（通用）：**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| ---- | ---- | ---- | ---- | ---- |
| page | int | 否 | 1 | 页码，从 1 开始 |
| size | int | 否 | 10 | 每页条数（对应 STU-01 默认 10 条/页） |

**响应结构：**

```json
{
  "code": 0,
  "msg": "成功",
  "data": {
    "total": 128,
    "page": 1,
    "size": 10,
    "list": []
  }
}
```

## 3. 认证模块

### 3.1 用户登录

- **接口说明**：用户名 + 密码登录，校验通过后签发 JWT，并返回角色信息供前端跳转对应首页。
- **请求**：`POST /api/auth/login`
- **权限**：公开（无需 Token）
- **请求参数（Body，JSON）**：

| 参数 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| username | string | 是 | 登录名（学号 / 工号 / 管理员账号） |
| password | string | 是 | 明文密码，后端使用 BCrypt 校验 |

**请求示例：**

```json
{ "username": "2025030227", "password": "123456" }
```

**成功响应：**

```json
{
  "code": 0,
  "msg": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9.eyJ1aWQiOjEsInJvbGUiOiJzdHVkZW50In0.xxx",
    "role": "student",
    "name": "夏同学",
    "expiresIn": 86400
  }
}
```

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| token | string | JWT 令牌，前端存入 `localStorage` |
| role | string | 角色：`admin` / `teacher` / `student` |
| name | string | 用户显示名称 |
| expiresIn | int | 有效期（秒） |

**失败响应：**

```json
{ "code": 1002, "msg": "用户名或密码错误", "data": null }
```

账号锁定（连续输错 5 次）：

```json
{ "code": 2001, "msg": "账号已锁定，请 10 分钟后再试", "data": null }
```

- **关联需求**：AUTH-01、AUTH-02、AUTH-03、AUTH-04

### 3.2 退出登录

- **接口说明**：清除登录态（前端同时清除本地 Token）。
- **请求**：`POST /api/auth/logout`
- **权限**：登录用户
- **请求参数**：无（Token 从请求头解析）
- **响应示例：**

```json
{ "code": 0, "msg": "已退出登录", "data": null }
```

- **关联需求**：AUTH-05

## 4. 个人中心模块

### 4.1 获取当前用户资料

- **接口说明**：返回当前登录用户的基本资料（不同角色字段不同）。
- **请求**：`GET /api/users/me`
- **权限**：登录用户
- **请求参数**：无
- **学生角色响应示例：**

```json
{
  "code": 0,
  "msg": "成功",
  "data": {
    "id": 6,
    "username": "2025030227",
    "role": "student",
    "name": "夏同学",
    "studentNo": "2025030227",
    "gender": "男",
    "department": "计算机学院",
    "major": "软件工程",
    "className": "软件2505班",
    "grade": "2025级",
    "phone": "13800002027",
    "email": "student@example.edu.cn",
    "address": "天津市"
  }
}
```

- **关联需求**：USR-01

### 4.2 修改个人资料

- **接口说明**：修改允许用户自行维护的字段（联系方式、邮箱、地址等）。
- **请求**：`PUT /api/users/me`
- **权限**：登录用户
- **请求参数（Body，JSON）**：

| 参数 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| phone | string | 否 | 手机号，11 位数字 |
| email | string | 否 | 邮箱，需合法格式 |
| address | string | 否 | 联系地址 |

**请求示例：**

```json
{ "phone": "13800002027", "email": "new@example.edu.cn" }
```

**成功响应：**

```json
{ "code": 0, "msg": "保存成功", "data": null }
```

- **关联需求**：USR-03

### 4.3 修改密码

- **接口说明**：校验旧密码后更新为新密码；修改成功后建议前端强制重新登录。
- **请求**：`POST /api/users/me/password`
- **权限**：登录用户
- **请求参数（Body，JSON）**：

| 参数 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| oldPassword | string | 是 | 原密码 |
| newPassword | string | 是 | 新密码，长度 ≥ 6 位 |

**请求示例：**

```json
{ "oldPassword": "123456", "newPassword": "abc12345" }
```

**成功响应：**

```json
{ "code": 0, "msg": "密码修改成功，请重新登录", "data": null }
```

**失败响应：**

```json
{ "code": 1001, "msg": "原密码不正确", "data": null }
```

- **关联需求**：USR-02、USR-04

## 5. 学生信息管理模块

### 5.1 学生列表（分页 + 搜索）

- **接口说明**：分页展示学生列表，支持按学号 / 姓名 / 班级模糊搜索。
- **请求**：`GET /api/students`
- **权限**：admin（全部）、teacher（仅任教班级，只读）
- **请求参数（Query）**：

| 参数 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| page | int | 否 | 页码，默认 1 |
| size | int | 否 | 每页条数，默认 10 |
| keyword | string | 否 | 学号 / 姓名 / 班级 模糊匹配 |
| classId | int | 否 | 按班级筛选 |

**请求示例：** `GET /api/students?page=1&size=10&keyword=软件`

**成功响应：**

```json
{
  "code": 0,
  "msg": "成功",
  "data": {
    "total": 128,
    "page": 1,
    "size": 10,
    "list": [
      {
        "id": 6,
        "studentNo": "2025030227",
        "name": "夏同学",
        "gender": "男",
        "className": "软件2505班",
        "phone": "13800002027",
        "email": "student@example.edu.cn"
      }
    ]
  }
}
```

- **关联需求**：STU-01

### 5.2 学生详情

- **接口说明**：按 id 查询单个学生完整档案。
- **请求**：`GET /api/students/{id}`
- **权限**：admin、teacher（teacher 仅限任教班级，学生仅可查看本人 → 建议学生走 `GET /api/users/me`）
- **成功响应：**

```json
{
  "code": 0,
  "msg": "成功",
  "data": {
    "id": 6,
    "studentNo": "2025030227",
    "name": "夏同学",
    "gender": "男",
    "birthDate": "2007-03-12",
    "classId": 5,
    "className": "软件2505班",
    "phone": "13800002027",
    "email": "student@example.edu.cn",
    "address": "天津市"
  }
}
```

- **关联需求**：STU-07

### 5.3 新增学生

- **接口说明**：新增学生档案，并**自动生成登录账号**（用户名 = 学号，初始密码由后端约定，如学号后 6 位）。
- **请求**：`POST /api/students`
- **权限**：admin
- **请求参数（Body，JSON）**：

| 参数 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| studentNo | string | 是 | 学号，唯一，格式「年级+专业代码+序号」 |
| name | string | 是 | 姓名 |
| gender | string | 是 | 枚举：男 / 女 |
| birthDate | string | 否 | 出生日期 `yyyy-MM-dd` |
| classId | int | 是 | 所属班级 ID |
| phone | string | 否 | 手机号，11 位数字 |
| email | string | 否 | 邮箱，合法格式 |
| address | string | 否 | 联系地址 |

**请求示例：**

```json
{
  "studentNo": "2025030228",
  "name": "李小明",
  "gender": "男",
  "birthDate": "2007-05-01",
  "classId": 5,
  "phone": "13900001234",
  "email": "lxm@example.edu.cn"
}
```

**成功响应：**

```json
{ "code": 0, "msg": "新增成功", "data": { "id": 129 } }
```

**失败响应：**

```json
{ "code": 1006, "msg": "学号已存在", "data": null }
```

- **关联需求**：STU-02

### 5.4 编辑学生

- **接口说明**：修改学生基本信息，**学号不可修改**。
- **请求**：`PUT /api/students/{id}`
- **权限**：admin
- **请求参数（Body，JSON）**：同「新增学生」，但 `studentNo` 不可变更。
- **成功响应：**

```json
{ "code": 0, "msg": "保存成功", "data": null }
```

- **关联需求**：STU-03

### 5.5 删除学生

- **接口说明**：逻辑删除（`is_deleted=1`，可恢复）；前端需二次确认。
- **请求**：`DELETE /api/students/{id}`
- **权限**：admin
- **成功响应：**

```json
{ "code": 0, "msg": "删除成功", "data": null }
```

- **关联需求**：STU-04

### 5.6 批量导入学生

- **接口说明**：上传 Excel 模板批量导入，逐行校验重复学号。
- **请求**：`POST /api/students/import`
- **权限**：admin
- **请求格式**：`multipart/form-data`

| 参数 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| file | file | 是 | Excel 文件（.xlsx/.xls） |

**成功响应：**

```json
{
  "code": 0,
  "msg": "导入完成",
  "data": { "total": 100, "success": 96, "failed": 4, "errors": ["第 3 行学号重复"] }
}
```

- **关联需求**：STU-05

### 5.7 导出学生

- **接口说明**：按当前筛选条件导出 Excel。
- **请求**：`GET /api/students/export`
- **权限**：admin
- **请求参数（Query）**：同「学生列表」筛选条件
- **响应**：二进制文件流（`Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`）
- **关联需求**：STU-06

| ---- | ---- | ---- | ---- |
| teacherNo | string | 是 | 工号，唯一 |
| name | string | 是 | 姓名 |
| gender | string | 是 | 枚举：男 / 女 |
| title | string | 否 | 职称：教授 / 副教授 / 讲师 / 助教 |
| deptId | int | 是 | 所属院系 ID |
| phone | string | 否 | 手机号，11 位数字 |
| email | string | 否 | 邮箱，合法格式 |

**请求示例：**

```json
{
  "teacherNo": "T2026031",
  "name": "陈老师",
  "gender": "女",
  "title": "讲师",
  "deptId": 1,
  "phone": "13600003031",
  "email": "chen@example.edu.cn"
}
```

**成功响应：**

```json
{ "code": 0, "msg": "新增成功", "data": { "id": 97 } }
```

**失败响应：**

```json
{ "code": 1006, "msg": "工号已存在", "data": null }
```

### 7.4 编辑教师

- **接口说明**：修改教师信息，**工号不可修改**。
- **请求**：`PUT /api/teachers/{id}`
- **权限**：admin
- **请求参数**：同「新增教师」，但 `teacherNo` 不可变更。
- **成功响应：**

```json
{ "code": 0, "msg": "保存成功", "data": null }
```

### 7.5 删除教师

- **接口说明**：逻辑删除；若该教师仍是某班级班主任或存在授课课程，则禁止删除。
- **请求**：`DELETE /api/teachers/{id}`
- **权限**：admin
- **失败响应：**

```json
{ "code": 1007, "msg": "该教师仍关联班级或课程，无法删除", "data": null }
```

## 9. 成绩管理模块

### 9.1 成绩列表

- **接口说明**：teacher 查看任教课程成绩，student 仅查看本人成绩，支持按学期 / 课程筛选。
- **请求**：`GET /api/scores`
- **权限**：登录用户
- **请求参数（Query）**：

| 参数 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| page | int | 否 | 页码，默认 1 |
| size | int | 否 | 每页条数，默认 10 |
| keyword | string | 否 | 课程名 / 课程编号模糊匹配 |
| semester | string | 否 | 学期筛选 |
| courseId | int | 否 | 课程筛选 |

**成功响应：**

```json
{
  "code": 0,
  "msg": "成功",
  "data": {
    "total": 5,
    "page": 1,
    "size": 10,
    "list": [
      {
        "id": 1,
        "courseId": 1,
        "courseName": "数据结构",
        "courseCode": "SE201",
        "teacherName": "王老师",
        "semester": "2026-2027-1",
        "usualScore": 92,
        "examScore": 88,
        "totalScore": 90,
        "credit": 4,
        "status": "已发布"
      }
    ]
  }
}
```

| status 字段 | 说明 |
| ---- | ---- |
| 已发布 / 未录入 | 成绩发布状态 |
| 缺考 | 对应 `status=1`（SCO-02） |
| 缓考 | 对应 `status=2`（SCO-02） |

- **关联需求**：SCO-04

### 9.2 录入成绩

- **请求**：`POST /api/scores`
- **权限**：teacher（仅本人任教课程）
- **请求参数（Body，JSON）**：

| 参数 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| courseId | int | 是 | 课程 ID |
| studentId | int | 是 | 学生 ID |
| usualScore | number | 否 | 平时分，0 ~ 100 |
| examScore | number | 否 | 考试分，0 ~ 100 |
| status | int | 否 | 0 正常 / 1 缺考 / 2 缓考 |

**请求示例：**

```json
{ "courseId": 1, "studentId": 6, "usualScore": 92, "examScore": 88, "status": 0 }
```

**成功响应：**

```json
{ "code": 0, "msg": "录入成功", "data": { "id": 40 } }
```

**失败响应（分数越界）：**

```json
{ "code": 1001, "msg": "成绩需在 0~100 之间", "data": null }
```

- **关联需求**：SCO-01、SCO-02

### 9.3 修改成绩

- **接口说明**：成绩提交锁定后如需修改，由教师申请或管理员操作，修改留痕。
- **请求**：`PUT /api/scores/{id}`
- **权限**：teacher（本人课程）、admin
- **请求参数**：同「录入成绩」
- **关联需求**：SCO-03

### 9.4 成绩统计

- **接口说明**：返回单科平均分、最高/最低分、及格率、分数段分布（供图表使用）。
- **请求**：`GET /api/scores/statistics`

- **成功响应：**

```json
{
  "code": 0,
  "msg": "成功",
  "data": {
    "courseId": 1,
    "courseName": "数据结构",
    "avgScore": 84.5,

    "minScore": 60,
    "passRate": 0.9,
    "distribution": [
      { "segment": "90-100", "count": 8 },
      { "segment": "80-89", "count": 15 },
      { "segment": "70-79", "count": 10 },
      { "segment": "60-69", "count": 5 },
      { "segment": "<60", "count": 3 }
    ]
  }
}
```

- **关联需求**：SCO-05

### 9.5 导出成绩单

- **请求**：`GET /api/scores/export`
- **权限**：teacher（本人课程）、admin
- **请求参数（Query）**：`courseId`
- **响应**：Excel 文件流
- **关联需求**：SCO-06
