# 演示演讲稿

> 方括号内是操作提示，正文直接念。

---

（浏览器停在登录页）

各位好，下面演示的是我们小组开发的**高校学生信息管理系统**。

刚才双击的一键启动脚本，依次做了这些事：自动申请管理员权限 → 清理上次残留的后端/前端进程 → 检测并启动 MySQL 服务 → CMake 增量编译后端 → 启动后端监听 8080 → 启动 Vite 前端监听 5173 → 自动打开浏览器。全程自动化，不需要手动敲命令。

好，演示分三段：管理员端、教师端、学生端，每段先说明该角色能使用的全部模块，再逐步演示关键功能。

---

【admin / password 登录】

首先进入管理员端。管理员拥有最高权限，可使用的模块包括：个人中心、组织架构管理、学生管理、教师管理、课程管理、成绩管理、公告管理。下面依次演示。

【点「个人中心」】
个人中心支持查看和修改个人联系方式，以及修改登录密码。

【点「院系/班级」】
组织架构模块分三个 Tab：院系管理、专业管理、班级管理，支持新增、编辑、删除各层级单位。

【点「学生管理」】
学生管理模块支持按姓名搜索、分页浏览、新增、编辑、删除学生信息。【输名字 → 回车】搜索筛选立即生效。这套搜索、筛选、分页的交互，在教师管理、课程管理、成绩管理中完全一致，后面不再重复演示。

【点「教师管理」】
教师管理模块功能与学生管理一致，略过。

【点「课程管理」】
课程管理是管理员端的核心模块。支持按关键词搜索课程、新增课程、编辑已有课程、删除课程。新增或编辑时可填写课程名称、学分、授课教师、开设班级、上课时间、上课地点等字段。【点「＋ 新建课程」→ 填写字段 → 保存】课程成功创建，列表刷新显示新记录。

【点「成绩管理」】
成绩管理模块支持按关键词（课程名/学生名/学号）搜索、按课程 ID 精确筛选、分页浏览全部成绩记录。管理员可新增成绩记录（选择课程、选择学生、填写分数和考试时间），可编辑、删除已有成绩，还可查看单门课程的统计数据——包括平均分、最高分、最低分、及格率和各分数段人数分布。【点某行「查看统计」】统计弹窗展示完整分布。

【点「公告管理」】
公告管理模块支持发布新公告、编辑公告内容、下线公告、删除公告。

---

【退出登录 → 20250101 / 250101 登录】

接下来进入教师端。教师登录后，系统自动切换到教师专属界面，可使用的模块为：教师工作台、我的课程、成绩录入、个人中心。

教师工作台首页展示四张统计卡片（授课课程数、覆盖学生数、已录入成绩数、平均分）、执教课程列表和四个快捷操作入口。

【点「我的课程」】
我的课程模块列出当前教师负责的全部课程，支持搜索筛选和分页，交互与管理员端课程列表一致。

【点「成绩录入」】
成绩录入模块列出当前教师负责课程的全部学生成绩，支持搜索筛选、录入新成绩、编辑已有成绩、删除成绩记录。交互与管理员端成绩管理一致。

【点「个人中心」】
与管理员端个人中心功能一致，略过。

---

【退出登录 → 2025030101 / 030101 登录】

最后进入学生端。学生登录后可使用的模块为：课程管理、成绩管理、个人中心。

【左侧菜单「课程管理」】
课程管理模块顶部展示四张统计卡片（本学期课程数、累计学分、授课教师数、正在开课数）。中部是本周课表视图，按周一至周日、一至十节排布，每门课按上课时间自动填入对应格子。下方是课程列表，支持搜索筛选、分页浏览。

【左侧菜单「成绩管理」】
成绩管理模块顶部展示四张统计卡片（已发布成绩数、平均分、已获学分、最高分）。列表展示每门课程的平时成绩、期末成绩、总评、学分、状态。支持按学期筛选、按关键词搜索。

【左侧菜单「个人中心」】
查看个人基本信息、修改联系方式、修改密码，略过。

---

以上就是本系统三个角色的完整功能演示。管理员管全局数据、教师管自己的课程和成绩、学生看自己的课表和成绩，各模块搜索、筛选、分页交互保持统一。演示完毕，谢谢大家。
