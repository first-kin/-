# 演示演讲稿

> 方括号内是操作提示，正文直接念。

---

（浏览器停在登录页）

各位好，下面演示的是我们小组开发的**高校学生信息管理系统**。

点击一键启动脚本，它会自动完成数据库、后端、前端的启动与环境检查，并自动打开浏览器，全程无需手动输入命令。

---

【admin / password 登录】

首先进入管理员端。管理员账号是 admin，初始密码就是 password，用它登录系统。

【点「个人中心」】
个人中心支持查看和修改个人联系方式，以及修改登录密码。这里我们将密码更改为 123456。

【点「院系/班级」】

院系和班级都支持新增、编辑、删除操作，可以随时维护学校的组织结构。

【点「学生管理」】【点「教师管理」】
学生管理和教师管理都提供查询功能，输入相应信息即可完成筛选查询；其中学生管理还支持将学生名单导出。

【点「课程管理」】
课程管理模块支持按关键词搜索课程、新增课程、编辑已有课程、删除课程。新增或编辑时可填写课程名称、学分、授课教师、开设班级、上课时间、上课地点等字段。【点「＋ 新建课程」→ 填写字段 → 保存】课程成功创建，列表刷新显示新记录。

【点「成绩管理」】
成绩管理模块支持按关键词（课程名/学生名/学号）搜索、按课程 ID 精确筛选、分页浏览全部成绩记录。管理员可新增成绩记录（选择课程、选择学生、填写分数和考试时间），查看单门课程的统计数据——包括平均分、最高分、最低分、及格率和各分数段人数分布。



---

【退出登录 → 20250101 / 250101 登录】

接下来进入教师端。教师系统的初始密码为工号后六位，例如当前账号 20250101，密码就是 250101。

教师工作台首页展示四张统计卡片，点击任意卡片可以直接跳转到对应模块。

【点「我的课程」】
我的课程模块列出当前教师负责的全部课程，支持搜索筛选和分页，交互与管理员端课程列表一致。

【点「成绩录入」】
成绩录入模块列出当前教师负责课程的全部学生成绩，支持搜索筛选、录入新成绩、编辑已有成绩、删除成绩记录。交互与管理员端成绩管理一致。

【点「个人中心」】
与管理员端个人中心功能一致，略过。

---

【退出登录 → 2025030101 / 030101 登录】

最后进入学生端。学生系统的初始密码为学号后六位，例如当前账号 2025030101，密码就是 030101。

【左侧菜单「课程管理」】
课程管理模块顶部展示四张统计卡片（本学期课程数、累计学分、授课教师数、正在开课数）。中部是本周课表视图，按周一至周日、一至十节排布，每门课按上课时间自动填入对应格子。下方是课程列表，支持搜索筛选、分页浏览。

【左侧菜单「成绩管理」】
成绩管理模块顶部展示四张统计卡片（已发布成绩数、平均分、已获学分、最高分）。列表展示每门课程的平时成绩、期末成绩、总评、学分、状态。支持按学期筛选、按关键词搜索。

【左侧菜单「个人中心」】
查看个人基本信息、修改联系方式、修改密码，略过。

---

以上就是本系统三个角色的完整功能演示。管理员管全局数据、教师管自己的课程和成绩、学生看自己的课表和成绩，各模块搜索、筛选、分页交互保持统一。演示完毕，谢谢大家。

（演示完删掉刚才新建的测试课程）
