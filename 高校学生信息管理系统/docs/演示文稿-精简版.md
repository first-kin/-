# 「知行」教务系统 · 演示脚本

> 只讲"有什么、怎么用"，不讲原理。
> 启动：双击 `一键启动.bat`，等浏览器跳登录页。

---

## 账号卡

| 角色 | 用户名 | 密码 |
|---|---|---|
| 管理员 | `admin` | `password` |
| 教师 | `20250101` | `250101` |
| 学生 | `2025030101` | `030101` |

---

## 管理员能做什么

### 登录 → 个人中心
- `admin / password` 登录，顶栏蓝色条出现所有 Tab
- 点「个人中心」→ 改手机号邮箱 → 保存；再改密码 → 成功

### 组织架构
- 点「院系/班级」→ 左侧树能展开学院/专业/班级；右侧三个 Tab 分别管院系、专业、班级；班级列表里有「所属学院」列

### 学生管理
- 点「学生管理」→ 搜索框输名字回车能筛选；分页正常翻

### 课程管理
- 点「课程管理」→ 列表有"开设班级"列
- 点「＋ 新建课程」→ 填课程名、选教师、选开设班级、学分、上课时间 → 保存
- 编辑、删除按钮能用

### 成绩管理
- 点「成绩管理」→ 搜索框能搜**课程名、学生名、学号**，课程 ID 精确筛选
- 点「＋ 录入成绩」→ 选课程、选学生、填分数 → 保存
- 每行右侧「查看统计」→ 出来平均分、最高分、及格率、分数段分布

### 公告管理
- 点「公告管理」→ 发布 / 编辑 / 下线

---

## 教师能做什么

### 登录 → 仪表盘
- 退出 → `20250101 / 250101` 登录
- 顶栏显示"教师工作台 / 我的课程 / 成绩录入 / 个人中心"
- 首页展示授课课程与本人任教课程的成绩统计

### 我的课程
- 点「我的课程」→ 列表只显示自己的课

### 成绩管理
- 点「成绩录入」→ 查看、录入和修改本人任教课程的成绩

---

## 学生能做什么

### 登录 → 课表
- 退出 → `2025030101 / 030101` 登录
- 左侧菜单「课程管理」→ 顶部四张统计卡；中间**本周课表**（周一~周日 × 1-10 节，1-2 节合并成一个蓝色块）；下方课程列表

### 成绩单
- 左侧菜单「成绩管理」→ 列表显示课程、学分、总评、状态
- 顶部四张统计卡（已发布门数、平均分、已获学分、最高分）
- 学期筛选下拉能用

### 个人中心
- 左侧菜单「个人中心」→ 改资料 / 改密码

退出登录 → 关掉浏览器。
